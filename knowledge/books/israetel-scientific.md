# Israetel et al. — Scientific Principles of Strength Training (RP)

## Rôle
**Pilote** pour la **dose** : volume, intensité, fatigue, deload.

## Apports retenus
- **MEV / MAV / MRV** : volume minimum efficace → volume adaptatif maximal → volume max récupérable.
- Overload : progresser le volume/intensité dans une zone récupérable ; au-delà du MRV = net négatif.
- **Fatigue management** : deloads systématiques ; ne pas confondre « dureté » et progrès.
- Spécificité, variation intelligente, individualisation.
- RPE / proximité de l’échec comme outils de régulation (utile post-blessure).

## Limites / écarté
- Applications powerlifting : patterns CF ≠ 3 lifts — on garde les **principes**, pas les splits PL.
- Hypertrophie pure : secondaire pour CF élite (sauf renfo gym / tissus).

## Pertinence athlète
Critique pour adducteur + 90 min : rester sous MRV, deload, progresser le **volume gym** sans casser la récupération.
