# S01 — 3–9 août 2026

**Meso** : Benchmarks · **Macrocycle 1 — Build** · **Saison 2026**

## Pourquoi / Intention / Apport / Suite

- **Pourquoi** : calibrer les charges actuelles avant le bloc Accumulation gym
- **Intention** : mesurer (RPE 8–9), pas ego-max
- **Apport** : charges actuelles fiables pour doser la suite
- **Suite** : Meso — Accumulation gym

### Fondements (corpus)

- **Israetel** (*Scientific Principles of Strength Training*) — sans 1RM / proxies actuels, les % et le dosage sont aveugles ; une semaine de tests avant Accumulation.
- **Issurin** (*Block Periodization*) — un bloc = une intention dominante ; Benchmarks = porte d’entrée avant Accumulation gym, pas un meso de développement.
- **Zatsiorsky** (*Science and Practice of Strength Training*) — intensité basée sur la capacité *actuelle*, pas sur les PRs pré-blessure.

## Règles

- 1–2 tests lourds max / jour
- Stop si douleur adducteur monte ; noter charge, reps, RPE, douleur 0–10
- Budget ~90 min (échauffement inclus) en semaine

## Lundi 03/08 — Lower (Back Squat)

<!-- pattern: benchmark_session -->
<!-- warmup: warmup_adductor_friendly -->

**Intention** : calibrer le squat structurel.

**Échauffement** (12–15’) :

1. Ergo easy 4–5’ (vélo préférable si adducteur sensible)
2. Mobilité douce adducteur : frog rock / cossack léger sans douleur 2–3’
3. Glute bridge ou hip thrust poids de corps 2×8
4. Squat progressif barre à vide → charges légères (pas de jump stretch agressif)
5. Stop et allège si douleur > 2/10 en montée

**Séance** :

1. Back squat — build jusqu’à **single RPE 8–9** OU meilleur **triple propre**
2. Core : 3×8–10 hollow rock ou roll-out
3. Finisher optionnel : zone 2 8–10’

## Vendredi 07/08 — Gym + Haltéro power

<!-- pattern: benchmark_session -->
<!-- warmup: warmup_gym_skill -->

**Intention** : baseline volume gym + confiance barre (power only).

**Échauffement** (10–12’) :

1. Ergo easy 3’
2. Scap + hollow / arch 2’
3. Drills spécifiques skill 4–6’ (BMU / HSPU / HSW légers)
4. 1–2 sets très submax avant le volume
5. Puis build Oly court : muscle snatch / tall clean barre vide → léger

**Séance — Gym** (qualité > quantité, 1–2 reps en réserve) :

- BMU : EMOM 8–10’ — noter reps stables / round
- RMU : EMOM 8’ — singles techniques (si temps)
- HSPU strict : 3–4 sets submax
- HSW : meilleure distance continue propre (m)

Si court en temps : prioriser BMU + HSPU + HSW.

**Séance — Haltéro** (10–15’) :

- Power snatch — charge lourde confortable (pas max out)
- Power clean — idem
- **Pas** de squat snatch/clean max
