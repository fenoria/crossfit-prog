## Pourquoi / Intention / Apport / Suite

- **Pourquoi** : calibrer les charges actuelles avant ACC-GYM
- **Intention** : mesurer (RPE 8–9), pas ego-max
- **Apport** : remplir les PRs actuels pour doser la suite
- **Suite** : Meso — ACC-GYM

### Fondements (corpus)

- **Israetel** (*Scientific Principles of Strength Training*) — sans 1RM / proxies actuels, les % et le dosage MEV→MAV sont aveugles ; un meso de tests avant Accumulation.
- **Issurin** (*Block Periodization*) — un bloc = une intention dominante ; Benchmarks = gate avant ACC-GYM, pas un meso de développement.
- **Zatsiorsky** (*Science and Practice of Strength Training*) — intensité basée sur la capacité *actuelle*, pas sur les PRs pré-blessure.

## Règles

- Noter : charge, reps, RPE, douleur adducteur 0–10
