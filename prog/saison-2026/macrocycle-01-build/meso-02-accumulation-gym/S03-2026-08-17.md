# S03 — 17–23 août 2026

**Meso** : Accumulation gym · **Macrocycle 1 — Build** · **Saison 2026**

## Objectif de la semaine

**Monter le volume** : densité EMOM ↑, RMU petites séries (cran 4), force maintien légèrement plus dense.

## Glossaire (cette semaine)

| Terme | Signification |
|-------|----------------|
| **RPE** | Effort perçu sur 10 |
| **Zone 2** | Cardio facile : parole en phrases possible |
| **EMOM / E2MOM** | Every (2) Minute On the Minute |
| **Couplet** | Deux mouvements enchaînés sans repos |
| **BMU / RMU / HSPU / HSW** | Voir S02 |

## Pourquoi / Intention / Apport / Suite

- **Pourquoi** : deuxième semaine ACC-GYM — le corps digère la baseline, on peut pousser le stimulus
- **Intention** : surcharge contrôlée sur gym (durée EMOM, petites séries) ; force/oly inchangés en intensité
- **Apport** : volume gym ~60–70 min qualité ; RMU cran 4 — séries 2–3 unbroken sous contrôle
- **Suite** : S04 pic densité — couplets gym + ergo si qualité intacte

### Fondements (corpus)

- **Israetel** — progresser vers MAV par paliers ; surveiller MRV (sommeil, RPE chronique, chute perf).
- **Low** — passer au cran suivant seulement si le cran actuel est propre (1–2 RIR).
- **Issurin** — surcharge = augmentation du stimulus du bloc dominant, pas du maintien.

## Règles

- Si **RPE chronique ≥ 8** sur les skills ou fatigue **≥ 4/5** en fin de semaine → garder les doses S02 en S04
- Back squat maintien : **≤ 115 kg**, **RPE ≤ 7**
- Mercredi team **RPE ≥ 8** → jeudi : **−1 round couplet** ou **EMOM −2’**
- Budget **~90 min** lun–ven

### Microcycle

**Phase micro** : surcharge — volume / densité ↑ vs S02

   - Noter si les BMU restent propres après l’ergo

**Renfo** :

3. Ring row feet-elevated **3×8–10** · repos 90 s
4. Ring dip **3×6–8** submax · repos 90 s
