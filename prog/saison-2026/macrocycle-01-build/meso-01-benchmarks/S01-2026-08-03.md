# S01 — 3–9 août 2026

**Meso** : Benchmarks · **Macrocycle 1 — Build** · **Saison 2026**

## Objectif de la semaine

**Mesurer** les charges actuelles — pas battre des records.

## Glossaire (cette semaine)

| Terme | Signification |
|-------|----------------|
| **RPE** | Effort perçu sur 10 (8 = 2 reps en réserve approx. ; 9 = 1 rep en réserve) |
| **Zone 2** | Cardio facile : parole en phrases possible ; ergo au choix (vélo / rameur / ski) |
| **Build** | Monter la charge en 4–6 sets d’approche, puis le set de test |
| **BMU / RMU** | Bar / Ring Muscle-Up |
| **HSPU** | Handstand Push-Up (strict = sans kipping) |
| **HSW** | Handstand Walk |

## Pourquoi / Intention / Apport / Suite

- **Pourquoi** : connaître les charges actuelles avant le bloc Accumulation gym
- **Intention** : tester proprement à RPE 8–9 — **pas de max à tout prix**
- **Apport** : chiffres fiables pour doser la suite
- **Suite** : bloc Accumulation gym (volume gym)

### Fondements (corpus)

- **Israetel** (*Scientific Principles of Strength Training*) — sans mesures actuelles, les % et le dosage sont aveugles ; une semaine de tests avant Accumulation.
- **Issurin** (*Block Periodization*) — un bloc = une intention dominante ; Benchmarks = porte d’entrée, pas un meso de développement.
- **Zatsiorsky** (*Science and Practice of Strength Training*) — intensité basée sur la capacité *actuelle*, pas sur d’anciens records.

## Règles

- **1–2 tests lourds max / jour** (les mouvements listés dans la séance)
- **Repos force** : 2–3 min entre sets lourds
- **Noter** pour chaque test : charge, reps, RPE
- **Build** : monter par paliers réguliers, garder les jumps larges au début puis plus petits près du top set
- Si douleur inhabituelle → allège ou stop le mouvement ; le noter en feedback
- Si **WOD team mercredi RPE ≥ 8** → jeudi : mêmes mouvements mais **−1 set d’approche** et **charges de test −10 à −15 %** (ou RPE cible −1)
- Budget **~90 min** (échauffement inclus) lun–ven

## Vendredi 07/08 — Gym + Haltéro power

<!-- pattern: benchmark_session -->
<!-- warmup: warmup_gym_skill -->

**Intention** : mesurer un volume gym stable + charges power snatch / power clean confortables.

**Échauffement** (10–12’) :

1. Ergo easy 3’
2. Tirages omoplates + hollow / arch 2’
3. Drills légers 4–6’ (BMU, HSPU, HSW — technique, pas de fatigue)
4. 1–2 sets très faciles du premier mouvement gym
5. Haltéro : muscle snatch + tall clean barre vide → léger, 3–4 min

**Séance — Gym** (qualité > quantité ; **toujours 1–2 reps en réserve**) :

| Mouvement | Format | Cible | Noter |
|-----------|--------|-------|-------|
| **BMU** | EMOM **10’** | **2–4 reps** chaque minute, rythme stable | reps / min + total |
| **RMU** | EMOM **8’** (si temps) | **1 rep** technique / min | réussi / raté |
| **HSPU strict** | **4 sets** | **3–6 reps** propres / set · repos 90–120 s | reps / set |
| **HSW** | **2–3 essais** | meilleure distance **continue propre** | mètres |

Si temps limité : **BMU + HSPU + HSW** seulement (laisser les RMU).

**Séance — Haltéro** (10–15’) :

1. **Power snatch** — 3–5 singles à **RPE 7–8** (lourd mais sûr, **aucun échec**), avec petits incréments de **2,5–5 kg** si la vitesse reste propre. Noter la charge max du jour.
2. **Power clean** — idem 3–5 singles RPE 7–8, incréments **2,5–5 kg**. Noter.
3. Stop dès perte de vitesse nette ou réception instable ; pas de squat snatch ni squat clean lourds
