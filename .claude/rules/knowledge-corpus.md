# Corpus `knowledge/`

- Génération séances : `knowledge/methodology.md` status **validated** + ops pack.
- Ne pas inventer de méthodo hors corpus sans le signaler ; évolution majeure → revalidation athlète.
- Synthèse ouvrage → `knowledge/books/<slug>.md` ; conflit auteurs → `knowledge/arbitrages.md`.
- **`books/`** : lecture **ciblée** uniquement si `knowledge/` insuffisant — ne jamais charger le corpus brut en masse.
- **Hors lecture par défaut** (archives) : `knowledge/arbitrages-archive.md`, `knowledge/methodology-changelog.md`, `athletes/<id>/history.yaml` — seulement pour retrouver un raisonnement détaillé.
- Générique ≠ instance : le calendrier (fenêtres, « SXX » à venir, samedis, paliers planifiés) vit dans `knowledge/instances/` ; ailleurs, une mention de semaine ne sert que de preuve passée.
